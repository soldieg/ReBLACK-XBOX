# Proposed roadmap

The sequence below is a working proposal. No dates or completion percentages are assigned until the project defines objective evidence for them.

## 1. Choose the next investigation

Select one function or subsystem from the existing XBE analysis and state what behavior or unresolved question matters.

## 2. Build an evidence path

Collect the relevant XboxRecomp disassembly/split, references, call path, data, and REA Evidence where supported. Record the exact target identity, source ranges, assumptions, and unresolved facts.

## 3. Reconstruct narrowly

Update one manual function reconstruction at a time. Keep generated lift output separate from human reconstruction and preserve the link to the source XBE and supporting notes.

## 4. Validate each result at the right level

Use a focused harness for the function contract. Treat a harness result as isolated validation; require emulator or gameplay evidence for claims about game behavior.

## 5. Expand project progress reporting

Replace the current one-function pilot with a reviewed inventory of all linked units, valid target objects, and source-built base objects. Keep analysis counts and incomplete pilot results separate from whole-game matching progress.

## 6. Integrate into the game project

Only after subsystem behavior is supported, integrate changes into the relevant XboxRecomp build and capture startup/runtime/gameplay evidence separately.
