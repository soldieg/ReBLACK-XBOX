# Archived dashboard template

The former interactive dashboard template is [`progress-dashboard-template-20261030.html`](progress-dashboard-template-20261030.html). Its publishing workflow is [`progress-dashboard-workflow-20261030.yml`](progress-dashboard-workflow-20261030.yml), moved out of `.github/workflows` so it no longer publishes the project homepage. The generated `data/progress.json` was not tracked, so this preserved template is not a self-contained working dashboard.

Historical records and data remain at their original paths. The active documentation focuses on the reconstructed source and evidence index at [`../../reconstructions/README.md`](../../reconstructions/README.md).
