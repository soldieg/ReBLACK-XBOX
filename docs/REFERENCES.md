# References and tools

These links provide project context or identify tools used in the local workflow. Their presence does not imply that their code or data is part of this repository.

- [Black-2006-Recomp](https://github.com/portingpete/Black-2006-Recomp) — related BLACK recompilation project consulted for technical context and comparison.
- [XboxRecomp](https://github.com/sp00nznet/xboxrecomp) — Xbox-aware XBE parsing, splitting, and recompilation tools used by this project.
- [REA (Reverse Engineer Anything)](https://github.com/morluto/rea) — reverse-engineering analysis and evidence capture for supported formats and providers. The original XBE is not accepted directly in the current workflow.
- [Ghidra](https://github.com/NationalSecurityAgency/ghidra) — static-analysis tool used where the input format and loader are supported.
- [objdiff](https://github.com/encounter/objdiff) — compares compiled reconstruction objects with target objects and produces the report consumed by the local progress dashboard.
- [OpenAI Codex](https://openai.com/codex/) — AI assistance for analysis, reconstruction, documentation, and workflow work.
- [decomp.dev project page](https://decomp.dev/soldieg/ReBLACK-XBOX) — historical external report destination. The repository's current dashboard is generated locally from its reviewed report snapshot and does not fetch from decomp.dev.
