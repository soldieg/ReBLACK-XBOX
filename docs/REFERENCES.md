# Tools and references

These references describe the tools and external context used in the Xbox reconstruction. Tool availability and a successful comparison do not by themselves prove complete semantics or Xbox runtime behavior.

- [XboxRecomp](https://github.com/sp00nznet/xboxrecomp) — XBE-aware parsing, splitting, and recompilation.
- [REA (Reverse Engineer Anything)](https://github.com/morluto/rea) — reverse-engineering analysis and evidence capture for supported formats and providers. The original XBE is not accepted directly by the recorded workflow.
- [Ghidra](https://github.com/NationalSecurityAgency/ghidra) — static analysis for supported inputs/loaders.
- [ObjDiff](https://github.com/encounter/objdiff) — object-code comparison used in the published reports.
- MSVC x86 — host compilation of the reconstructed function modules; see the [complete package](../reconstructions/codigo-completo/README.md) for flags and limits.
- [OpenAI Codex](https://openai.com/codex/) — AI assistance for analysis, reconstruction, documentation, and workflow work under human direction and review.
- [decomp.dev project page](https://decomp.dev/soldieg/ReBLACK-XBOX) — historical external report destination; the public source/evidence package is in this repository.
