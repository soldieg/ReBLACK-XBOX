# ReBlack Xbox Project — BLACK from Xbox to PC

[![objdiff progress](docs/assets/progress.svg)](https://soldieg.github.io/ReBLACK-XBOX/)

The project aims to decompile and reconstruct *BLACK* for the original Xbox, then work toward a PC recompilation.

**Status:** XBE analysis and function-by-function reconstruction are in progress. The dashboard shows objdiff matches in an incomplete candidate snapshot; it is not a whole-game completion percentage.
